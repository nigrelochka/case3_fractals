# Фрактальная мастерская

Учебная программа на Python для рисования девяти фракталов с помощью рекурсии и библиотеки `turtle`.

В меню можно выбрать фрактал и задать глубину рекурсии, размер рисунка, а для двоичного дерева — угол ветвей.

## Запуск

1. Установите Python 3.10 или новее.
2. Запустите `main.py`:

```bash
python main.py
```

Выберите номер фрактала в консоли и введите параметры. Рисунок появится в отдельном окне.

## Структура

- `main.py` — меню, ввод параметров и запуск рисования.
- `fractals/basic.py` — дерево и ветка.
- `fractals/koch.py` — кривая Коха, снежинка Коха и кривая Минковского.
- `fractals/complex.py` — ледяные фракталы, кривая Леви и дракон.

`develop` — рабочая ветка, `main` — версия проекта для сдачи.
