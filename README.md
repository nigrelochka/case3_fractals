# Фрактальная мастерская

Учебный проект на Python с рекурсивным построением девяти фракталов через `turtle`.

## Ветки
- `main` — стабильная версия; не изменяем до финальной сдачи.
- `develop` — единственная рабочая ветка всей команды.

## Структура
- `main.py` — роль 4: меню и интеграция.
- `fractals/basic.py` — роль 1: дерево и ветка.
- `fractals/koch.py` — роль 2: Кох и Минковский.
- `fractals/complex.py` — роль 3: ледяные фракталы, Леви и дракон.
- `tests/` — тесты.

## Запуск
```bash
python main.py
```

Пока это каркас проекта: функции фракталов содержат заглушки `pass`, а интерфейс показывает только меню. Реализация будет добавляться командой в `develop`.
