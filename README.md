# Фрактальная мастерская

Командный учебный проект на Python: рекурсивное построение фракталов с помощью turtle.

- `main` — финальная стабильная версия (не изменять до завершения разработки).
- `develop` — единственная рабочая ветка всех участников.

Разработка ведётся в `develop`; в конце готовый проект переносится в `main`.
